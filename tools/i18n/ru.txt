Установка
«Слово узнаётся по компании, в которой оно бывает» (Дж. Р. Фёрс, 1957).
Введите слово, и Synoikon соберёт сотни реальных предложений с ним, рассмотрит слова вокруг каждого вхождения и нарисует их в виде сети:
<b>Площадь круга</b> = как часто сосед встречается рядом с вашим словом (по умолчанию в окне ± 5 слов).
<b>Длина линии</b>: чем чаще два слова встречаются в одном контекстном окне, тем <b>короче</b> (и толще) линия между ними.
Сортировка <b>Характерные</b> (по умолчанию) выделяет слова, которые встречаются рядом с вашим словом намного чаще, чем в обычном тексте языка (лог-отношение к фоновому списку на основе Википедии, с фильтром значимости log-likelihood). Сортировка <b>Частота</b> просто показывает самых частых соседей.
Каждый день в 00:00 UTC появляется новое слово дня, одно для всех. Оно берётся из подобранного списка 66 выразительных понятий, переведённых на каждый язык (<a href="./#wotd">слово сегодня</a>). Слова на сегодня и следующие два дня, а также ежедневная подборка популярных слов <b>рассчитываются заранее</b> задачей GitHub Actions, поэтому открываются мгновенно и работают офлайн. Любое другое слово ваш браузер загружает в реальном времени.
Ваши запросы идут напрямую из браузера к API Wikimedia и Algolia (с идентификатором «LessThan301 synoikon»). У Synoikon нет сервера, и он ничего о вас не хранит.
Приложение кэширует на устройстве свои файлы, используемые языковые данные и недавние результаты (service worker), чтобы работать офлайн. Очистите данные сайта, чтобы удалить их.
Посещения считаются с помощью <a href="https://www.cloudflare.com/web-analytics/">Cloudflare Web Analytics</a>, без cookie и без отпечатков браузера.
Synoikon — устанавливаемое веб-приложение: используйте «Установить приложение» в разделе <em>Отображение и экспорт</em> на панели настроек (Chrome, Edge, Android) или «На экран „Домой“» в меню «Поделиться» Safari (iOS).
